# Your freelance portfolio

A responsive React + Vite portfolio starter. Replace the placeholder name, email and WhatsApp number before publishing.

## Run locally

1. Install Node.js (current supported LTS).
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.
4. Run `npm run build` before deployment.

## Personalise before sharing

- In `src/App.jsx`, replace `YOUR NAME`, `hello@example.com`, and `971500000000`.
- Update the About copy to reflect your real experience and strengths.
- Replace the concept project cards with real links/screenshots as you build them. Keep concept work labelled honestly.
- Test every link, mobile layout and contact method.

## Deploy

Push this folder to a GitHub repository. Import the repository in Vercel. Vercel should detect Vite; use build command `npm run build` and output directory `dist` if asked.
